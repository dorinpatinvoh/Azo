1. En résumé

Entre le 30 septembre et le 12 octobre 2026, le serveur est passé d'un projet vide à une plateforme complète : connexion par code SMS, dossiers prestataires avec pièces d'identité, tarification Zem et voitures, mise en relation par proximité, suivi de course en temps réel, paiement et portefeuille (dont FedaPay), notifications poussées, langues, profil, messagerie et pourboire. Il est hébergé sur Render avec une base PostgreSQL.

Les commits sont signés de plusieurs identités (dorinpatinvoh, PATINVOH, Esther.W, charafath) : ils correspondent à l'équipe du binôme et sont regroupés ici sans distinction.

Lecture : ce rapport est reconstitué à partir de l'historique Git (messages de commits) et des rapports déjà présents dans le dépôt. Les correspondances avec les fichiers DEMANDE_BACKEND_*.md sont déduites des sujets de commits.

4. Ce que la plateforme faisait à la fin de cette phase

  • Comptes : connexion par code SMS (1 minute de validité, 3 essais par heure et par numéro), blocage immédiat d'un compte suspendu.
  • Prestataires : dossier avec photos, validation par l'administrateur, journal d'audit de chaque étape, espaces Agence / Coursier / Admin.
  • Tarifs : une seule source (tarification.json) ; Zem essence et électrique, voitures Gazelle / Koala / Léopard ; commissions et frais de retrait par profil.
  • Course : demande, radar par proximité, acceptation, arrivée, code de départ, course, code d'arrivée, paiement du portefeuille vers le Zem, annulation, arrêt anticipé d'un commun accord.
  • Temps réel : position du Zem et du client, chat de course, mises à jour de statut.
  • Argent : portefeuille AZƆ̀ Pay, recharge FedaPay, historique des transactions.
  • Exploitation : déploiement Render, sonde /health, migrations appliquées au démarrage, données de démonstration.

5. Points laissés à la reprise

  • Le Zem pouvait rester bloqué sur « 0 s » quand la proposition se terminait (traité ensuite par Sergio).
  • Le client n'était pas alerté en temps réel quand un Zem acceptait (traité ensuite par Sergio).
  • 7 tests automatiques échouaient (tarif électrique et pseudo du client) : corrigés ensuite.
  • Aucune route GET /pricing côté serveur.
