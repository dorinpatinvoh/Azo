1. En résumé

Trois changements côté mobile : une inscription simplifiée pour les profils professionnels (le numéro seul), le tricycle réservé aux gros colis et la plaque du Speeder partiellement masquée. Tout compile (tsc sans erreur).

À savoir avant de tester : rien de ce rapport n'a été essayé sur un téléphone. Le backend doit être déployé avant l'APK (le serveur enregistre le type de compte à la vérification du code). Priorités de test : l'inscription de chaque profil (Client, Speeder course simple, coursier personnel, livreur express, agence de flotte), puis la reconnexion d'un professionnel qui n'a pas fini son dossier.

2. Inscription : l'identité ne concerne que le client

  • Client : inchangé — formulaire Nom, Prénom, Sexe, NPI après le code reçu.
  • Speeder (course simple), coursier personnel, livreur express : l'écran « Créer un compte » ne demande que le numéro de la personne. Après le code, l'application ouvre directement le dossier dédié (type d'activité et spécialité du coursier conservés). Plus de nom, sexe ni NPI à cette étape.
  • Agence de flotte : seul le numéro est demandé, avec le libellé « Numéro du représentant ou du propriétaire (10 chiffres) » (fr, en, es, de : auth.phone.labelAgency) ; le texte d'aide du choix du type de compte précise que seul le numéro est demandé.
  • Le choix du type de compte a disparu de l'écran du formulaire d'identité (il ne sert plus qu'au client) ; OtpLoginScreen.tsx envoie le type au serveur lors de la vérification du code (authApi.verifyOtp(…, profil)).
  • Reconnexion : un professionnel dont le dossier est encore en brouillon retrouve son dossier sans repasser par l'identité ; si son dossier est déposé ou validé, le parcours habituel du prestataire s'applique.
  • Limite : un professionnel n'a ni nom ni NPI enregistrés ; s'il veut aussi commander comme client, il devra remplir le formulaire d'identité (non vérifié que l'application le lui propose clairement).

3. Colis : le tricycle ne livre que les gros colis

  • « Envoyer un colis » : document, petit et moyen colis ne proposent que le Speeder à essence et l'électrique ; « Gros colis » ne propose que le tricycle ; le Speeder se réajuste si le type de colis change.
  • Depuis l'accueil, choisir « Speeder tricycle » pour une livraison ouvre la commande avec « Gros colis » sélectionné ; texte « Pour les gros colis uniquement ». La course simple et le coursier personnel en tricycle ne changent pas.

4. Plaque du Speeder

Le client voit la plaque partiellement : début et fin visibles, milieu caché (ex. « AB123****CD »). Le mobile affiche simplement ce que renvoie le serveur ; aucun changement de code mobile.

5. Cartes et recherche de lieux

Aucun changement de code mobile : la recherche d'adresse et la position affichée profitent de la nouvelle base de lieux du serveur (voir le rapport backend), après déploiement.
