1. En résumé

Nouveauté : le parrainage. L'administrateur crée des parrains ; un prestataire saisit le code de son parrain à l'inscription ; le parrain suit ses filleuls dans un espace dédié. Tout compile (tsc sans erreur).

À savoir avant de tester : rien de ce rapport n'a été essayé sur un téléphone. Le backend doit être déployé avant l'APK (nouvelle migration 20261018100000_referrals). Priorités de test : créer un parrain depuis l'onglet Parrains, se connecter avec son numéro, inscrire un Speeder avec son code, puis regarder les chiffres chez le parrain.

2. Console administrateur : onglet « Parrains »

  • Nouvel onglet Parrains dans la barre du bas de l'administrateur (AdminTabBar.tsx, écran AdminReferralsScreen.tsx).
  • Ajouter : nom complet, numéro de téléphone, note facultative. Le parrain reçoit un code AZO-XXXXXX (fenêtre de confirmation avec « Partager le code »). Un numéro déjà utilisé par un client inscrit ou un prestataire est refusé.
  • Liste : une carte par parrain avec le nombre de Speeders, d'agences, de coursiers et de livreurs, et le détail actifs / inactifs / en attente / ont rechargé (avec le total rechargé).
  • Fiche d'un parrain : les mêmes chiffres, la liste complète des filleuls (numéros complets), « Rattacher un prestataire » (par son numéro), « Retirer de ce parrain » sur chaque filleul, « Désactiver / Réactiver » le parrain.

3. Espace du parrain

  • Le parrain se connecte avec son numéro (code SMS) et arrive directement dans Espace parrain (ReferrerHomeScreen.tsx), sans formulaire d'identité. L'application retient ce profil au redémarrage (valeur de rôle « REFERRER » côté appareil).
  • Son code en grand, avec « Partager mon code » (message prêt à envoyer).
  • Chiffres par catégorie (ReferralOverview.tsx) : Speeders, agences, coursiers personnels, livreurs express ; toucher une catégorie filtre la liste. Vue d'ensemble : parrainés, actifs, inactifs, en attente, et « N ont rechargé leur compte » avec le total rechargé.
  • Filtres : tous, actifs, inactifs, en attente, ont rechargé.
  • Fiche de chaque filleul : nom, catégorie, numéro partiellement masqué, ville, état, date d'inscription, date de validation, dernière activité, missions au total et sur 30 jours (flotte pour une agence), recharges (nombre, montant, dernière date).
  • Actualisation en tirant l'écran et toutes les 30 s ; déconnexion avec confirmation.
  • Règles : « Actif » = dossier validé et au moins une course ou livraison terminée ces 30 derniers jours ; « Inactif » = dossier validé sans activité récente.

4. Inscription d'un prestataire avec un code de parrainage

  • Sur « Créer un compte », pour Speeder, coursier personnel, livreur express et agence : champ « Code de parrainage (facultatif) » sous le numéro (OtpLoginScreen.tsx). Le code est envoyé à la vérification du code reçu par SMS ; casse et espaces ignorés.
  • Code inconnu, désactivé ou invalide : fenêtre « Ce code est inconnu ou n'est plus valable. Ton inscription continue sans parrain. » ; l'inscription n'est jamais bloquée.
  • Le champ n'existe pas pour le Client : un client n'est jamais rattaché à un parrain.

5. Limites

  • Les textes du parrainage sont en français uniquement.
  • Pas de récompense ni de commission pour les parrains : suivi seulement.
  • Pour un livreur ou un coursier, la « dernière activité » s'appuie sur la date de la commande (une livraison n'a pas d'heure de fin enregistrée).
