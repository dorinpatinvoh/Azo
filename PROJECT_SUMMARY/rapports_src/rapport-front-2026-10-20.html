1. En résumé

Nouveauté : les commerciaux (commercialage). L'administrateur crée des commerciaux ; un prestataire saisit le code de son commercial à l'inscription ; le commercial suit ses recrues dans un espace dédié. Tout compile (tsc sans erreur).

À savoir avant de tester : rien de ce rapport n'a été essayé sur un téléphone. Le backend doit être déployé avant l'APK (nouvelle migration 20261018100000_referrals). Priorités de test : créer un commercial depuis l'onglet Commerciaux, se connecter avec son numéro, inscrire un Speeder avec son code, puis regarder les chiffres chez le commercial.

1bis. Code promo « COM-AZO001 » et lien personnel

  • Le code promo d'un commercial est COM-AZO + son numéro d'ordre (COM-AZO001, COM-AZO002…). À l'inscription, la saisie ignore la casse, les espaces et le tiret ; les anciens codes AZO-XXXXXX restent acceptés.
  • Lien personnel : https://azo.angidsnpro.com/?ref=COM-AZO001#telecharger (page de téléchargement du site, avec le code). Le commercial le voit dans son espace (onglet Mon lien) et l'administrateur dans la fiche du commercial ; chacun peut le partager (message prêt pour WhatsApp, SMS…) avec CommercialPromoCard.tsx.
  • Limite : l'application est téléchargée depuis un fichier Google Drive, le code ne peut pas voyager dedans. Le site doit afficher le code (petit script à coller une fois dans la page : PROJECT_SUMMARY/SITE_CODE_COMMERCIAL.md) et la personne le saisit à l'inscription ; le remplissage automatique est une suite possible (presse-papiers ou Google Play).
  • Espace du commercial à 4 onglets (barre du bas, CommercialHomeScreen.tsx) : Accueil (code promo, partage, chiffres par catégorie, trois dernières recrues), Recrues (liste avec filtres par état et catégorie), Mon lien (code, lien, « Comment ça marche »), Profil (nom, numéro, code, ancienneté, déconnexion). Le bouton retour du téléphone revient d'abord à l'accueil.

2. Console administrateur : onglet « Commerciaux »

  • Nouvel onglet Commerciaux dans la barre du bas de l'administrateur (AdminTabBar.tsx, écran AdminReferralsScreen.tsx).
  • Ajouter : nom complet, numéro de téléphone, note facultative. Le commercial reçoit un code COM-AZO001 (fenêtre de confirmation avec « Partager le code »). Un numéro déjà utilisé par un client inscrit ou un prestataire est refusé.
  • Liste : une carte par commercial avec le nombre de Speeders, d'agences, de coursiers et de livreurs, et le détail actifs / inactifs / en attente / ont rechargé (avec le total rechargé).
  • Fiche d'un commercial : les mêmes chiffres, la liste complète des recrues (numéros complets), « Rattacher un prestataire » (par son numéro), « Retirer de ce commercial » sur chaque recrue, « Désactiver / Réactiver » le commercial.

3. Espace du commercial

  • Le commercial se connecte avec son numéro (code SMS) et arrive directement dans Espace commercial (ReferrerHomeScreen.tsx), sans formulaire d'identité. L'application retient ce profil au redémarrage (valeur de rôle « REFERRER » côté appareil).
  • Son code en grand, avec « Partager mon code » (message prêt à envoyer).
  • Chiffres par catégorie (ReferralOverview.tsx) : Speeders, agences, coursiers personnels, livreurs express ; toucher une catégorie filtre la liste. Vue d'ensemble : commercialés, actifs, inactifs, en attente, et « N ont rechargé leur compte » avec le total rechargé.
  • Filtres : tous, actifs, inactifs, en attente, ont rechargé.
  • Fiche de chaque recrue : nom, catégorie, numéro partiellement masqué, ville, état, date d'inscription, date de validation, dernière activité, missions au total et sur 30 jours (flotte pour une agence), recharges (nombre, montant, dernière date).
  • Actualisation en tirant l'écran et toutes les 30 s ; déconnexion avec confirmation.
  • Règles : « Actif » = dossier validé et au moins une course ou livraison terminée ces 30 derniers jours ; « Inactif » = dossier validé sans activité récente.

4. Inscription d'un prestataire avec un code de commercialage

  • Sur « Créer un compte », pour Speeder, coursier personnel, livreur express et agence : champ « Code de commercialage (facultatif) » sous le numéro (OtpLoginScreen.tsx). Le code est envoyé à la vérification du code reçu par SMS ; casse et espaces ignorés.
  • Code inconnu, désactivé ou invalide : fenêtre « Ce code est inconnu ou n'est plus valable. Ton inscription continue sans commercial. » ; l'inscription n'est jamais bloquée.
  • Le champ n'existe pas pour le Client : un client n'est jamais rattaché à un commercial.

5. Limites

  • Les textes du commercialage sont en français uniquement.
  • Pas de récompense ni de commission pour les commerciaux : suivi seulement.
  • Pour un livreur ou un coursier, la « dernière activité » s'appuie sur la date de la commande (une livraison n'a pas d'heure de fin enregistrée).

6. Console d'administration sur le web (nouveau)

Toutes les fonctions de l'administrateur sont reprises sur un site web séparé (dossier admin-web, Vite + React), qui parle à la même API que l'application.

  • Écrans : tableau de bord ; dossiers des prestataires (pièces visibles, validation pièce par pièce, validation avec dérogation, refus, demande d'information, suspension, rétablissement) ; utilisateurs (recherche, blocage, remise à zéro des notes, NPI) ; finances (résumé, commissions de 15 % avec Speeder et course, retraits à payer ou annuler) ; commerciaux (création, code et lien à copier, rattachement) ; support (réponses, clôture) ; corrections d'identité ; location de voitures ; journal d'audit.
  • Connexion : numéro + mot de passe (plus de code SMS pour l'administrateur). Session de 12 h, déconnexion automatique si le serveur refuse le jeton.
  • Hébergement : site statique envoyé sur Cloudflare (adresse en workers.dev), construit avec l'adresse de l'API de production. Aucun secret dans le site.
  • Sur l'application mobile : les écrans administrateur existent encore, mais la connexion administrateur par code SMS est refusée (voir rapport backend). Leur retrait est à décider.
  • Vérifié dans un vrai navigateur sur une base jetable (26 vérifications sur 26, captures d'écran). Non vérifié : usage réel sur la production avec le vrai mot de passe.
