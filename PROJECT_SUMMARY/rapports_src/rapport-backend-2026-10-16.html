1. En résumé

Deux changements côté serveur, tous dans delivery/ : un devis de colis (GET /deliveries/quote) qui donne au client exactement le prix que le serveur facturera, et la règle « gros colis = Speeder tricycle uniquement ». Aucune migration aujourd'hui. Je n'ai pas vérifié le déploiement Render (/health doit afficher fc6f3fb5).

À vérifier : (1) le devis utilise OSRM, et à défaut la distance à vol d'oiseau × 1,3 : si OSRM est indisponible depuis Render, le prix peut être plus élevé que la distance réelle (§2) ; (2) le prix affiché au client et le prix facturé viennent du même calcul, mais sont deux appels OSRM distincts : un écart de quelques dizaines de mètres est possible.

2. Devis de colis (GET /deliveries/quote)

  • Paramètres : vehicleType, packageType, pickupLat, pickupLng, dropLat, dropLng. Réponse : { km, price } (distance de l'itinéraire arrondie à 0,1 km ; prix = base du colis + km × tarif au km du Speeder).
  • Tarifs (delivery.vehicles dans tarification.json, mis à jour dans le 2e commit du jour) : Speeder moto (essence et électrique) 70 F/km avec une base selon le type de colis (baseByPackage : doc 100 F, small 120 F, medium 200 F) ; tricycle 225 F + 80 F/km pour tous les types (dont large). Exemple à 1 km : document 170 F, petit colis 190 F, colis moyen 270 F en essence ; 305 F en tricycle. PricingService.deliveryRule(vehicule, typeDeColis) et deliveryPrice portent le type de colis ; le matin, le tarif était 200 + 80 pour toutes les motos.
  • Refus (400) : véhicule sans tarif de livraison (voitures), type de colis non proposé pour ce véhicule (ex. gros colis en moto), coordonnées invalides.
  • La création d'un colis (POST /deliveries) recalcule le prix de la même façon : le prix envoyé par le client reste ignoré.
  • La route est déclarée avant les routes à paramètre d'identifiant ; elle exige l'authentification comme le reste du contrôleur.

3. Gros colis

  • Un colis de type large est refusé (400, « Un gros colis se livre en Speeder tricycle. ») pour tout autre Speeder. Le type reste une chaîne libre côté base (aucune migration).

Tests ajoutés (personal-courier.spec.ts, 20 tests au total) : devis à 1 km par type de colis (170 / 190 / 270 F en essence, 305 F en tricycle) ; prix à la création (petit colis 10 km = 820 F) ; gros colis refusé en moto et accepté en tricycle.
