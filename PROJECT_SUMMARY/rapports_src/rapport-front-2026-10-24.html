1. En résumé

Choix du Speeder : les cartes Speeder à essence, électrique et tricycle ont chacune un visuel fourni par AZO en fond. L'accueil client est plus sobre et ses cartes de services vibrent 1 seconde toutes les 30 secondes. Les notifications push sont branchées côté Android (fichier Firebase + plugin). L'onboarding reste en test : les photos ne s'affichaient pas. tsc sans erreur.

À savoir avant de tester : je n'ai vu aucun écran sur un téléphone ; les retours viennent des captures de Sergio. Les push n'ont pas encore été vus fonctionner. Désinstaller l'ancienne version avant d'installer l'APK (icône et onboarding). La console doit être reconstruite avec VITE_API_URL=https://azo-backend.onrender.com avant d'être renvoyée sur Cloudflare.

2. Cartes du choix du Speeder (course)

  • Essais successifs d'après les captures : photo Wikimedia à 45 % (trop pâle), puis en couleurs avec un voile blanc dégradé (texte peu lisible par endroits), puis voile renforcé. Version finale : trois visuels fournis par AZO (assets/moto_essence.png, moto_electrique.png, moto_tricycle.png), placés à droite de la carte sur fond blanc pur (le gris du fond est poussé vers le blanc), à 55 % d'opacité ; le fond du tableau des prix est blanc à 72 %. Les cartes voiture n'ont pas de visuel.

  • Droits : ces trois visuels montrent des modèles de marque ; vérifier qu'AZO a le droit de les publier. Les photos Wikimedia (CC BY-SA 4.0) ne sont plus utilisées sur ces cartes ; CREDITS_PHOTOS.md est à jour.

3. Accueil client

  • Toutes les 30 secondes, les 3 cartes Speeder et les 5 cartes de services tremblent pendant 1 seconde (va-et-vient de 3 px, légère inclinaison), seulement si l'application est au premier plan et si l'utilisateur n'a pas réduit les animations dans Android. Vibration visuelle (pas du moteur du téléphone).
  • Accueil sobre : sous-titres et pastilles « Populaire » / « Sécurisé » retirés, bannière écologique retirée (commits du 23 octobre).

4. Notifications push : côté application

  • Cause d'absence de push : app.json référence google-services.json, mais le fichier n'existait pas ; Android ne pouvait pas créer de jeton, et l'application n'affichait aucune erreur (le jeton revient « vide »).
  • Le bon fichier (projet Firebase azo-push-74d5b, paquet bj.azo.app) a été copié dans azo-mobile/ et android/app/ ; trois autres fichiers du dossier Téléchargements appartenaient à une autre application et n'ont pas été utilisés. Le plugin com.google.gms.google-services a été ajouté au projet Android ; la configuration est bien présente dans l'APK compilé.
  • Hors dépôt : le fichier est ignoré par git et le dossier android n'est pas suivi ; si le dossier est régénéré (expo prebuild), refaire l'ajout du plugin et du fichier. La clé FCM V1 est, d'après Sergio, déposée chez Expo.
  • Test à faire : installer l'APK du jour, se connecter, accepter les notifications, commander une course ; application en arrière-plan, la notification « Commande envoyée » doit apparaître. Sinon, journaux Render (voir rapport backend).

5. Onboarding : toujours ouvert

  • Quatre pages, photo plein écran, texte au-dessus des quatre points, police réduite, sans ligne de crédit à l'écran. Les photos n'apparaissaient pas au dernier test (les fichiers sont dans l'APK, les JPEG sont normaux).
  • Essai en cours, non commité : photos redimensionnées à 720 px et intégrées au code (assets/onboarding/photos.ts, SplashScreen.tsx) ; la même méthode fonctionne pour les cartes du Speeder. Pas de retour de test à ce jour. S'il fonctionne : commiter.
  • Licence : photos CC BY-SA 4.0 ; afficher les noms des auteurs dans l'application (par exemple « À propos ») avant la mise en ligne publique.

6. Problèmes rencontrés (diagnostic)

  • « NPI déjà utilisé » à l'inscription : un NPI ne peut appartenir qu'à un seul compte. Supprimer les comptes de test avant lundi ; une recherche par NPI dans la console est proposée, pas faite.
  • Connexion refusée pour un numéro : messages possibles — compte bloqué, compte administrateur (mot de passe sur la console), trop de demandes de code, ou compte supprimé (le numéro est libre, la connexion crée un compte vide). Cause réelle non identifiée faute du message exact.
